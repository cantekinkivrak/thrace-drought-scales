# code/revision_gee — per-scene Landsat table: compositing, masks, scene filters

`code/09_gee_revision_extractions.ipynb` (Google Earth Engine; generated by `build_nb09.py`) exports
`data/rev_scene_means_1985_2024.csv.gz`: for every Landsat 5/7/8/9 scene and district, the mean NDVI
and LST and the number of valid 30 m pixels under ten masks (CORINE 1990, 2000, 2006, 2012, 2018,
their intersection, ESA WorldCover 2021 cropland, wheat-like and sunflower-like phenology masks, no
mask), with sensor and SLC-off flags. It also exports `data/rev_district_landcover_fractions.csv`,
`data/rev_phenology_fractions.csv` and `data/rev_september_green.csv`.

The scripts below run from the repository root, read that table and write to `data/revision_results/`.

| Script | Produces | Used in |
|---|---|---|
| `H5_build_median_vhi.py` | rebuilds `data/trakya_district_vhi_vci_tci_monthly.csv` — the primary monthly **median** composite (NDVI and LST medians taken separately) with VCI/TCI/VHI; checks the maximum composite against the v1.0.x file | all primary results |
| `H2_gee_postprocess.py data/rev_scene_means_1985_2024.csv.gz` | `H2_gee_summary.csv`, `H2_gee_selection_tables.csv` — mask vintages, compositing operators (max/mean, mean, median, same-scene, max/max), SLC-off and Landsat-7 ablations, Landsat 8/9 only, crop masks × windows | Table S3 (b, c), Table S6 |
| `H3_ipsala_scene_quality.py` | `H3_ipsala_scene_quality.csv`, `H3_ipsala_subperiods.csv`, `H3_ipsala_vci_tci.csv`, `H3_ipsala_gap_ci.csv` — coverage filters, sub-periods, VCI/TCI components, paired plateau–İpsala bootstrap | Section 3.5, Table S1 (difference), Table S3 (c), Figure 5 |
| `H4_windows_qc.py` | `H4_windows_qc.csv` — seasonal windows under the maximum, QC-filtered and median composites and within the phenology masks | Table S6 |
| `H6_max_inflation.py` | `H6_max_inflation.csv` — monthly maximum minus median NDVI by district; share of maxima from SLC-off scenes | Section 3.5, Figure 5c |
| `H7_median_sensitivity.py` | `H7_median_sensitivity.csv` — scale selection and İpsala coupling under every mask, vintage and scene filter with the median composite | Table S3 (a) |
| `fig56.py` | `figures/Fig5_compositing_artefact.png`, `figures/Fig6_season_dependent_scales.png` | Figures 5–6 |
